# Dummy Energy Data Generator

I needed a way to create a lot of fake energy usage data for a hackathon.

This C# application uses a list of streets in Gateshead, along with several name lists, to generate a set of dummy data and write it to a CSV file.

The output will contain daily usage records for each address containing a date, name, address, gas and elecricity usage figures.
